
# Task 1: Iris Flower Classification

## Overview
This project classifies Iris flowers into Setosa, Versicolor, or Virginica species using machine learning based on floral measurements.

## Work Done
- Conducted Exploratory Data Analysis (EDA) with Seaborn pairplots and boxplots.
- Built and evaluated Logistic Regression and Decision Tree models.
- Calculated Accuracy, Confusion Matrix, and Precision/Recall/F1-scores.
