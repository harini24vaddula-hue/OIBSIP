## 🛠️ Tasks Completed

### 1. Task 1: Iris Flower Classification
* **Objective:** Train a machine learning classification model to identify the species of an Iris flower based on its physical measurements.
* **Tech Stack:** Python, Pandas, Matplotlib, Seaborn, Scikit-learn, Jupyter Notebook.
* **Key Steps:**
  * Loaded the Iris dataset directly using Scikit-learn.
  * Conducted Exploratory Data Analysis (EDA) using pair plots and box plots.
  * Split data into 80/20 train-test sets.
  * Trained and evaluated K-Nearest Neighbors (KNN) and Random Forest classifiers.
  * Generated a confusion matrix and achieved high classification accuracy.

### 2. Task 2: Unemployment Analysis with Python
* **Objective:** Perform exploratory analysis on unemployment rate metrics in India to uncover spatial patterns and assess the impact of COVID-19 pandemic lockdowns.
* **Tech Stack:** Python, Pandas, Matplotlib, Seaborn, Jupyter Notebook.
* **Key Steps:**
  * Cleaned and preprocessed time-series data (date formatting and null value checks).
  * Generated region-wise bar charts to highlight state-level unemployment variations.
  * Visualized time-series trends before and after the March 2020 COVID-19 lockdown.
  * Created correlation heatmaps across labor metrics (unemployment rate, employed count, and labor participation rate).
  * Formulated key analytical observations explaining pandemic-induced economic disruptions.
